# Yeyo QR App

Yeyo QR App is a Flutter-based mobile application designed for fast and secure **QR code scanning and driver verification**. The app is production-ready and officially **published on the Google Play Store**.

---

## Status

 Development completed  
 Firebase integrated  
 Production-ready  
 Published on Google Play Store  

---

## Features

- QR code scanning for driver verification  
- Instant approval / rejection feedback  
- Secure scan history storage using Firebase  
- Multi-language support (English & French)  
- User-configurable settings (sound, vibration, history)  
- Optimized for performance and stability  

---

## Tech Stack

- **Flutter (Dart)**
- **Firebase (Firestore)**
- **SharedPreferences**
- **Android Play App Signing**

---

## Security & Best Practices

- Sensitive files (keystore, Firebase config) are excluded from version control  
- Firebase rules configured for production use  
- Play App Signing enabled
